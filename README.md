

## Задание 3: UI-автотесты для Stellar Burgers

Проект по автоматизации UI-тестов веб-приложения Stellar Burgers.

Тесты написаны с использованием Page Object.

## Что проверяется

В проекте реализованы автотесты для основной функциональности приложения:

* переход по клику на раздел «Конструктор»;
* переход по клику на раздел «Лента заказов»;
* открытие всплывающего окна с деталями ингредиента;
* закрытие всплывающего окна с деталями ингредиента;
* увеличение счётчика ингредиента при добавлении ингредиента в заказ.

Также реализованы автотесты для раздела «Лента заказов»:

* увеличение счётчика «Выполнено за всё время» после создания заказа;
* увеличение счётчика «Выполнено за сегодня» после создания заказа;
* отображение номера созданного заказа в разделе «В работе».

## Браузеры

Тесты запускаются в двух браузерах:

* Google Chrome;
* Mozilla Firefox.

## Используется

* Python;
* Pytest;
* Selenium WebDriver;
* Allure;
* Page Object.


## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

Для запуска всех тестов:

```bash
python -m pytest tests -v
```

## Запуск тестов с Allure

Для запуска тестов с сохранением результатов Allure:

```bash
python -m pytest tests --alluredir=allure_results
```

## Описание файлов

* `pages/base_page.py` — базовые методы для работы со страницами;
* `pages/main_page.py` — методы главной страницы и конструктора;
* `pages/feed_page.py` — методы страницы «Лента заказов»;
* `pages/login_page.py` — методы страницы авторизации;
* `pages/register_page.py` — методы страницы регистрации;
* `pages/locators.py` — локаторы элементов;
* `tests/test_main_functionality.py` — тесты основной функциональности;
* `tests/test_order_feed.py` — тесты ленты заказов;
* `conftest.py` — фикстуры для запуска браузеров и подготовки пользователя;
* `data.py` — тестовые данные;
* `urls.py` — URL приложения.
